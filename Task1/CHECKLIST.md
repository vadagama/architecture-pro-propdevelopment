# Проверочный лист по безопасности данных PropDevelopment

## 1. Классификация данных (ISO/IEC 27001/27002)

| Категория            | Данные                                                                                              | Источник в системе                                               |
| -------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **Публичные**        | Каталог объектов недвижимости (адрес, планировка, площадь, цена)                                    | client-mart-estate-app, Витрина продаж                           |
| **Публичные**        | Маркетинговые материалы 3D-туров                                                                    | client-tour-app                                                  |
| **Внутренние**       | Операционные данные CRM (история взаимодействий менеджеров с клиентами)                             | client-crm-app, crm-db                                           |
| **Внутренние**       | Аналитические отчёты и BI-дашборды                                                                  | Хранилище данных (Greenplum), DWH (S3)                           |
| **Внутренние**       | Данные о статусе ремонтных работ и обслуживании ЖК                                                  | tenant-core-app, tenant-core-db                                  |
| **Внутренние**       | Логи и метаданные интеграций (CDC-потоки, Kafka-события)                                            | Все БД -> Хранилище данных                                       |
| **Конфиденциальные** | Персональные данные клиентов (ФИО, телефон, e-mail, данные расширенной формы)                       | client-crm-app, crm-db (MSSQL)                                   |
| **Конфиденциальные** | Персональные данные собственников (ФИО, контакты, данные о собственности)                           | CRM собственников, crm-tenant-db (PostgreSQL)                    |
| **Конфиденциальные** | Данные об оплате ЖКУ (суммы, история платежей, лицевые счета)                                       | tenant-core-app, Платёжная система                               |
| **Конфиденциальные** | Данные «Умного дома» (состояние устройств, доступ к замкам)                                         | tenant-core-app                                                  |
| **Секретные**        | Данные онлайн-сделок (договоры купли-продажи, юридические документы, данные паспортов)              | client-mart-app, client-mart-db                                  |
| **Секретные**        | Финансовые и бухгалтерские данные (проводки, расчёты, налоговая отчётность)                         | accountant-service-1, auth-db-1 (финансы)                        |
| **Секретные**        | Учётные данные и токены аутентификации (credentials, сессии, ключи API)                             | auth-service-1 (Keycloak), Active Directory                      |
| **Секретные**        | Данные интеграции с госорганами (СМЭВ — регистрационные данные, персональные данные для госорганов) | client-mart-app -> Государственные регистрационные органы (SOAP) |
