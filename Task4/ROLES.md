| Роль             | Права роли                                                                                                                                                                                                   | Группы пользователей                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| cluster-admin    | Полный доступ ко всем ресурсам кластера: управление нодами, пространствами имён, RBAC, секретами, PersistentVolumes, NetworkPolicies и всеми другими ресурсами. Привилегированная роль.                      | DevOps-инженеры, Специалист по ИБ                |
| namespace-editor | Создание, изменение и удаление рабочих нагрузок в пространствах имён: Deployments, Services, ConfigMaps, Ingresses, Jobs, CronJobs, Pods, HPA. Без доступа к Secrets и управлению RBAC.                      | Разработчики, Инженеры по эксплуатации           |
| namespace-viewer | Просмотр (get, list, watch) всех ресурсов в пространствах имён: Pods, Deployments, Services, ConfigMaps, Ingresses, Jobs, Events, Logs. Без доступа к Secrets.                                               | Бизнес-аналитики, Менеджеры, Владельцы продуктов |
| secret-manager   | Просмотр и управление секретами (get, list, create, update, delete Secrets) во всех пространствах имён. Привилегированная роль для работы с конфиденциальными данными (ключи API, credentials, сертификаты). | Специалист по ИБ, DevOps-инженеры                |
